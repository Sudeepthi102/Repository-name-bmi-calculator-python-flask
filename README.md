# 🧮 BMI Calculator Using Python & Flask

A simple and interactive BMI Calculator web application developed using Python and Flask.

The application allows users to enter their weight and height and automatically calculates their Body Mass Index (BMI). It also displays the corresponding BMI category.

## 📌 Project Overview

BMI stands for Body Mass Index. It is a simple calculation based on a person's weight and height.

The application provides an easy-to-use interface where users can:

- Enter their weight in kilograms
- Enter their height in centimeters
- Calculate their BMI
- View their BMI value
- View their BMI category

## 🚀 Features

- Simple and user-friendly interface
- BMI calculation using Python
- Flask-based backend
- HTML form for user input
- Jinja2 template rendering
- Responsive design
- Aqua and purple gradient background
- 3D card effects
- Button hover effects
- Animated background
- Floating elements
- Animated BMI result section

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- Jinja2
